BekenIot User Guide
=======================================

:link_to_translation:`zh_CN:[中文]`

Download BekenIoT App: `BekenIoT App download <https://docs.bekencorp.com/arminodoc/bk_app/app/en/v2.0.1/app_download/index.html>`_

Sign-up, login, and provisioning are the same for every project. Stream format, resolution, whether a panel is used, and low-power / intercom behavior are in each project's documentation.

1. Install the App, then sign up and log in
2. Add a device and select ``Video Doorbell``
3. Pick non-5G Wi-Fi and provision over BLE
4. Tap the scanned device whose IP matches to finish provisioning
