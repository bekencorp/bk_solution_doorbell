BekenIot 使用说明
=======================================

:link_to_translation:`en:[English]`

下载 BekenIoT App：`BekenIoT App下载 <https://docs.bekencorp.com/arminodoc/bk_app/app/zh_CN/v2.0.1/app_download/index.html>`_

各工程的注册、登录与配网相同。配网之后的图传格式、分辨率、是否带屏以及低功耗见各参考工程文档。

1. 设备上电
2. 在 Android 测试机安装 App，注册并登录
3. 添加设备，选择 ``可视门铃``（建议先选 ``BK7258_DL_01`` 试用）
4. ``开始添加``，选择非 5G Wi-Fi，通过蓝牙配网
5. 在扫描到的设备中点击 IP 匹配的项，完成配网
