博通集成 BK7258 门铃方案
=====================================

:link_to_translation:`en:[English]`

	这是博通集成 BK7258 门铃解决方案开发框架的官方文档。

	本方案基于 **BK7258** 主控与 **BK AVDK SMP（Armino SMP SDK）v3.1.x**，提供可视门铃、低功耗保活门铃、MJPEG 兼容显示以及 4M 变体等端到端示例工程，覆盖 UVC/DVP 采集、H.264 / MJPEG 图传、LCD、双向音频、BLE 配网与 AP 掉电保活。

	BK AVDK SMP 平台文档请参考 `Armino SMP（中文） <https://docs.bekencorp.com/arminodoc/bk_avdk_smp/smp_doc/bk7258/zh_CN/v3.1.1/index.html>`_ ；`英文文档 <https://docs.bekencorp.com/arminodoc/bk_avdk_smp/smp_doc/bk7258/en/v3.1.1/index.html>`_ 同步提供。
