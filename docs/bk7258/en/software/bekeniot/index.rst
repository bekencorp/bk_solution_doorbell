BekenIot User Guide
=======================================

:link_to_translation:`zh_CN:[中文]`

Download BekenIoT App: `BekenIoT App download <https://docs.bekencorp.com/arminodoc/bk_app/app/en/v2.0.1/app_download/index.html>`_

Sign-up, login, and provisioning are the same for every project. Stream format, resolution, whether a panel is used, and low-power behavior are in each project's documentation.

1. Power on the device
2. Install the App on an Android test phone, then sign up and log in
3. Add a device and select ``Video Doorbell`` (try ``BK7258_DL_01`` first)
4. Tap ``Start Adding``, pick non-5G Wi-Fi, and provision over BLE
5. Tap the scanned device whose IP matches to finish provisioning
