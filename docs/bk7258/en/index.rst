Beken BK7258 Doorbell Solution
=====================================

:link_to_translation:`zh_CN:[中文]`

	This is the official documentation for the Beken BK7258 Doorbell Solution development framework.

	The solution is built on the **BK7258** SoC and **BK AVDK SMP (Armino SMP SDK) v3.1.x**. It provides end-to-end example projects for video doorbell, low-power keepalive, MJPEG-compatible display, and the 4M variant, covering UVC/DVP capture, H.264 / MJPEG streaming, LCD, two-way audio, BLE provisioning, and AP power-down keepalive.

	For BK AVDK SMP documentation, see `Armino SMP (English) <https://docs.bekencorp.com/arminodoc/bk_avdk_smp/smp_doc/bk7258/en/v3.1.1/index.html>`_ or `Armino SMP (中文) <https://docs.bekencorp.com/arminodoc/bk_avdk_smp/smp_doc/bk7258/zh_CN/v3.1.1/index.html>`_.
